## 🚀 Featured Projects

### 1. 🤖 Document Question Answering System Using RAG and LLMs

**Tech Stack:** Python, LangChain, FAISS, Hugging Face Transformers, Sentence Transformers, Streamlit, PyPDF

- Developed an AI-powered document question-answering application using Retrieval-Augmented Generation (RAG).
- Enabled users to upload PDF documents and ask questions using natural language.
- Implemented semantic search using vector embeddings and the FAISS vector database.
- Integrated Large Language Models (LLMs) to generate context-aware answers based on retrieved document content.
- Built an interactive user interface using Streamlit.

### 2. 🧾 Billora — GST Billing and Invoice Management System

**Tech Stack:** Java, Spring Boot, Spring Security, React.js, MySQL, JWT

- Developed REST APIs for invoice creation, viewing, sorting, and management.
- Implemented JWT-based authentication and role-based access control using Spring Security.
- Integrated PDF and Excel report generation for financial records.
- Implemented email functionality for sending invoices using Java Mail API.
- Built a full-stack billing solution with a React frontend and Spring Boot backend.

### 3. 📁 Customized Virtual File System

**Tech Stack:** C, Linux, Data Structures

- Developed a virtual file system that simulates core file management operations.
- Implemented inode tables, file tables, and User File Descriptor Table (UFDT) concepts.
- Created custom shell commands for file operations.
- Applied operating system and file management concepts in a practical implementation.

### 4. 📦 File Packer–Unpacker

**Tech Stack:** Java, Java Swing, File Handling, MD5

- Developed a desktop application to pack multiple files into a single file and unpack them when required.
- Preserved file data and associated metadata during packing and extraction.

- Designed a graphical user interface using Java Swing.
